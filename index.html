GrammaCore Pipeline

1

Input Validation & Span Masking

Text is validated (max 2,000 characters). Protected spans — LaTeX ($…$), inline code (`…`), and URLs — are replaced with numbered placeholders so the model cannot alter them.

2

T5-Base Grammar Correction

The masked text is prefixed with "grammar: " and fed to the vennify/t5-base-grammar-correction model via beam search (5 beams, 3 candidates). The model outputs corrected text along with per-token log-probabilities.

3

Span Unmasking

Placeholders are restored to their original content, ensuring LaTeX math, inline code, and URLs come through byte-for-byte unchanged.

4

Edit Detection & Alignment

Word-level alignment (via SequenceMatcher) between the original and corrected text identifies individual edits (insertions, deletions, replacements).

5

Per-Edit Confidence Scoring

Each edit gets a different confidence score derived from the mean token probability (via compute_transition_scores) of the generated tokens covering that span. This is NOT the sentence-level score — each edit has its own value.

6

Categorisation & Explanation

Each edit is categorised (grammar, spelling, punctuation, style, redundancy, word choice) using heuristic rules. A misspelled word (not in spaCy vocabulary, edit distance ≤ 2) is labelled spelling. Punctuation-only changes are labelled punctuation. Explanations quote the actual words involved.

7

Threshold & Suggestions

Edits with confidence below the user-set threshold are returned as "suggestions" (shown but not auto-applied). The user can accept or reject each edit individually.

8

Alternative Candidates

Other beam candidates are checked for genuinely different corrections for each span. Only real, distinct alternatives are shown — no filler options.

Model Details

  • Model: vennify/t5-base-grammar-correction (HuggingFace)
  • Architecture: T5-base (220M parameters), encoder-decoder transformer
  • Input prefix: "grammar: "
  • Inference: CPU only, beam search with 5 beams
  • Vocabulary check: spaCy en_core_web_sm
  • Evaluation dataset: JFLEG (jhu-clsp/jfleg)
